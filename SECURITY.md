# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Report security problems privately to the repository owner through GitHub.

## Principles

AI DevOps follows these principles:

- least-privilege GitHub permissions;
- no secrets in source code;
- evidence-first AI findings;
- no automatic trust in model output;
- strict structured output validation;
- explicit uncertainty handling.

AI-generated findings are advisory and should be verified by a human before
being treated as a confirmed security vulnerability.
